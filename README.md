# 🌺 SuBitkim / My Water Plant

🇹🇷 Günlük su içme alışkanlığını oyunlaştıran, sanal bitki büyütme temalı mobil uygulama.  
🇬🇧 A gamified daily hydration tracking mobile app where your virtual plant grows as you drink water.

---

## 🇹🇷 Türkçe

### ✨ Öne Çıkan Özellikler
- **🌺 5 Aşamalı İnteraktif Sanal Bitki:** Günlük su hedefine yaklaşma oranına göre bitkin 5 farklı evreden geçer (`🥀` → `🌱` → `🪴` → `🌷` → `🌺`) ve dokunduğunda yaylanma animasyonuyla tepki verir.
- **💧 Hızlı ve Özel Su Ekleme:** Kademeli hızlı seçim butonlarıyla (`✓` +150 ml, `✓✓` +200 ml, `✓✓✓` +330 ml, `✓✓✓✓` +500 ml) tek dokunuşla su ekleyebilir veya özel mililitre girişi yapabilirsin.
- **🎯 Düzenlenebilir Günlük Hedef:** Varsayılan `2000 ml` hedefini uygulama içinden doğrudan güncelleyebilir, ilerlemeni canlı yüzde çubuğuyla takip edebilirsin.
- **🔥 Günlük Seri (Streak) ve Geri Alma:** Hedefini tamamladığında günlük serin artar; hatalı girişlerde **Geri Al** veya **Günü Sıfırla** seçenekleriyle kolayca düzeltme yapabilirsin.
- **🌗 Akıllı Gece / Gündüz Teması:** Günün saatine göre otomatik tema seçer ve tek dokunuşla temalar arasında geçiş imkânı sunar.

### 🛠️ Kullanılan Teknolojiler
- React Native
- Expo
- TypeScript
- React Native Animated API

## 🇬🇧 English

### ✨ Key Features
- **🌺 5-Stage Interactive Virtual Plant:** Your plant evolves through 5 visual stages (`🥀` → `🌱` → `🪴` → `🌷` → `🌺`) based on your daily hydration progress and reacts with a spring animation when tapped.
- **💧 Quick & Custom Water Logging:** Log water in one tap using tiered preset buttons (`✓` +150 ml, `✓✓` +200 ml, `✓✓✓` +330 ml, `✓✓✓✓` +500 ml) or enter any custom milliliter amount.
- **🎯 Customizable Daily Goal:** Edit your daily target inline (default `2000 ml`) and track completion with a live progress bar.
- **🔥 Daily Streak & Undo Controls:** Build your daily completion streak and fix mistakes anytime with **Undo** or **Reset Day**.
- **🌗 Smart Dark / Light Mode:** Automatically adapts to the time of day with a manual theme toggle.

### 🛠️ Tech Stack
- React Native
- Expo
- TypeScript
- React Native Animated API
